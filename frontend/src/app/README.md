# Next.js App Directory (`src/app`)

This directory contains the App Router files for the Cybersecurity Analyst frontend.

---

## Files

1. **[`favicon.ico`](./favicon.ico)**: Application icon in the browser tab.
2. **[`globals.css`](./globals.css)**: Global CSS styling, color variables, and Tailwind imports.
3. **[`layout.tsx`](./layout.tsx)**: Root layout component, font configuration, and metadata.
4. **[`page.tsx`](./page.tsx)**: Main interactive page component managing file uploads and analysis execution.
